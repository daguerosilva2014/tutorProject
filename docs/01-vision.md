# Visión del producto

## Nombre provisional

Sistema de gestión para academias pequeñas.

## Problema

Las academias pequeñas suelen gestionar alumnos, clases, asistencia y pagos mediante planillas, mensajes y registros separados. Esto dificulta conocer cuántas clases utilizó cada alumno, qué clases puede recuperar, cuánto pagó y qué deuda mantiene.

## Solución

El sistema centralizará la gestión de alumnos, profesores, materias, clases, asistencia, recuperaciones, paquetes de clases y pagos.

La academia tendrá una base general de alumnos. Los profesores crearán clases concretas y asignarán manualmente a los alumnos que participarán. No existirán grupos o comisiones permanentes en la primera versión.

## Usuarios objetivo

- Administrador de la academia.
- Profesores.

Los alumnos no utilizarán directamente el sistema durante el MVP.

## Alcance inicial

El MVP permitirá:

- administrar alumnos activos e inactivos;
- administrar profesores y materias;
- crear clases;
- asignar alumnos;
- registrar asistencia;
- gestionar recuperaciones;
- crear paquetes de clases;
- registrar pagos totales y parciales;
- consultar clases utilizadas y restantes;
- consultar deudas;
- conservar un historial de modificaciones.

## Principios del producto

- Mantener un registro histórico confiable.
- Separar asistencia, consumo de clases y pagos.
- Permitir recuperar clases cuando el aviso se realiza con anticipación.
- No eliminar el historial de los alumnos inactivos.
- Priorizar una interfaz simple y clara.
- Evitar funcionalidades que la academia todavía no necesita.

## Fuera del alcance inicial

- Aplicación móvil.
- Portal para alumnos.
- Pagos online.
- Facturación electrónica.
- Integración con WhatsApp.
- Múltiples instituciones o sedes.
- Reportes avanzados.

## Indicadores de éxito

El sistema será útil si permite:

- saber rápidamente cuántas clases le quedan a un alumno;
- identificar pagos parciales y deudas;
- consultar la asistencia histórica;
- registrar recuperaciones sin duplicar consumos;
- conocer quién modificó información;
- reactivar alumnos sin perder sus antecedentes.
